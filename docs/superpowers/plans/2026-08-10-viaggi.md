# Viaggi, rotte e scorrimento continuo — Piano di implementazione

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** trasformare i posti indipendenti in tappe di un viaggio percorribile con un'unica
scorsa, con la mappa che vola da una tappa all'altra lungo una rotta tratteggiata, e dare
un menu da cui creare viaggi e tappe senza toccare un magnete.

**Architecture:** `places` si spezza in `trips` + `stops`; la chiave di cifratura e il
token di scrittura salgono dal posto al viaggio, così un solo frammento di URL apre tutte
le tappe. La pagina diventa un unico documento con la mappa in una fascia fissa in alto,
guidata da un `IntersectionObserver` che chiede voli a un regista che li ridirige invece
di accodarli.

**Tech Stack:** TypeScript, Vite, Hono su Cloudflare Workers, D1, R2, MapLibre GL JS,
Vitest (`lib` in happy-dom + `worker` in workerd), Playwright (WebKit iPhone + Chrome).

```sql
-- I posti smettono di essere isole: diventano tappe di un viaggio.
--
-- Ricostruzione da zero e non conversione: niente è mai stato deployato, e l'unico dato
-- esistente è un posto di prova sul database locale. Portarsi dietro una conversione per
-- un solo record costerebbe più di quanto vale.
--
-- La chiave di cifratura e il token di scrittura appartengono ora al VIAGGIO: è quello
-- che rende possibile scorrere da una tappa all'altra decifrando con un'unica chiave.

DROP TABLE IF EXISTS photos;
DROP TABLE IF EXISTS places;

CREATE TABLE trips (
  slug             TEXT PRIMARY KEY,   -- id casuale, non compare mai in un URL del browser
  name             TEXT NOT NULL,
  write_token_hash TEXT NOT NULL,      -- SHA-256 esadecimale del token di scrittura
  created_at       INTEGER NOT NULL
);

CREATE TABLE stops (
  slug       TEXT PRIMARY KEY,         -- id casuale, è questo che sta nell'URL del tag NFC
  trip_slug  TEXT NOT NULL REFERENCES trips(slug) ON DELETE CASCADE,
  name       TEXT NOT NULL,
  lat        REAL NOT NULL,
  lon        REAL NOT NULL,
  created_at INTEGER NOT NULL
);

CREATE TABLE photos (
  id         TEXT PRIMARY KEY,
  stop_slug  TEXT NOT NULL REFERENCES stops(slug) ON DELETE CASCADE,
  r2_key     TEXT NOT NULL,   -- blob cifrato, versione grande
  thumb_key  TEXT NOT NULL,   -- blob cifrato, miniatura
  width      INTEGER NOT NULL,
  height     INTEGER NOT NULL,
  taken_at   INTEGER,         -- da EXIF, NULL se la foto non ce l'ha
  sort_index INTEGER NOT NULL,
  created_at INTEGER NOT NULL
);

CREATE INDEX idx_stops_trip  ON stops(trip_slug, created_at);
CREATE INDEX idx_photos_stop ON photos(stop_slug, sort_index);
```

```ts
  height: number;
```

```ts
/**
 * Tutte le query su D1. Nessun'altra parte del Worker scrive SQL.
 *
 * Le righe grezze restano confinate qui: verso l'esterno escono solo i DTO condivisi,
 * così i nomi delle colonne possono cambiare senza toccare le rotte.
 */

import type { PhotoDto, StopDto, TripSummaryDto, TripViewDto } from '../shared/api-types';

export interface PhotoRow {
  id: string;
  stop_slug: string;
  r2_key: string;
  thumb_key: string;
  width: number;
  height: number;
  taken_at: number | null;
  sort_index: number;
  created_at: number;
}

interface StopRow {
  slug: string;
  trip_slug: string;
  name: string;
  lat: number;
  lon: number;
  created_at: number;
}

function toPhotoDto(row: PhotoRow): PhotoDto {
  return {
    id: row.id,
    key: row.r2_key,
    thumbKey: row.thumb_key,
    width: row.width,
    height: row.height,
    takenAt: row.taken_at,
    sortIndex: row.sort_index,
  };
}

export async function insertTrip(
  db: D1Database,
  trip: { slug: string; name: string; writeTokenHash: string },
): Promise<void> {
  await db
    .prepare('INSERT INTO trips (slug, name, write_token_hash, created_at) VALUES (?, ?, ?, ?)')
    .bind(trip.slug, trip.name, trip.writeTokenHash, Date.now())
    .run();
}

export async function tripExists(db: D1Database, tripSlug: string): Promise<boolean> {
  const row = await db.prepare('SELECT 1 AS uno FROM trips WHERE slug = ?').bind(tripSlug).first();
  return row !== null;
}

/** Falso se il viaggio non esiste: una tappa orfana non deve poter nascere. */
export async function insertStop(
  db: D1Database,
  stop: { slug: string; tripSlug: string; name: string; lat: number; lon: number },
): Promise<boolean> {
  if (!(await tripExists(db, stop.tripSlug))) return false;

  await db
    .prepare('INSERT INTO stops (slug, trip_slug, name, lat, lon, created_at) VALUES (?, ?, ?, ?, ?, ?)')
    .bind(stop.slug, stop.tripSlug, stop.name, stop.lat, stop.lon, Date.now())
    .run();

  return true;
}

/**
 * Il viaggio intero a partire da una sua tappa, che è il modo in cui ci si arriva sempre:
 * l'URL del tag NFC contiene la tappa, non il viaggio.
 *
 * L'ordine delle tappe è la data della foto più vecchia di ciascuna. Le tappe ancora
 * vuote non hanno una data e finiscono in fondo, in ordine di creazione — è l'unico
 * ordine sensato per qualcosa che non è ancora successo.
 */
export async function getTripByStop(db: D1Database, stopSlug: string): Promise<TripViewDto | null> {
  const trip = await db
    .prepare(
      `SELECT t.slug, t.name
         FROM trips t
         JOIN stops s ON s.trip_slug = t.slug
        WHERE s.slug = ?`,
    )
    .bind(stopSlug)
    .first<{ slug: string; name: string }>();

  if (!trip) return null;

  const { results: stops } = await db
    .prepare(
      `SELECT s.*, (SELECT MIN(p.taken_at) FROM photos p WHERE p.stop_slug = s.slug) AS first_taken_at
         FROM stops s
        WHERE s.trip_slug = ?
        ORDER BY (first_taken_at IS NULL) ASC, first_taken_at ASC, s.created_at ASC`,
    )
    .bind(trip.slug)
    .all<StopRow & { first_taken_at: number | null }>();

  const { results: photos } = await db
    .prepare(
      `SELECT p.*
         FROM photos p
         JOIN stops s ON s.slug = p.stop_slug
        WHERE s.trip_slug = ?
        ORDER BY p.sort_index ASC`,
    )
    .bind(trip.slug)
    .all<PhotoRow>();

  const perStop = new Map<string, PhotoDto[]>();
  for (const photo of photos) {
    const list = perStop.get(photo.stop_slug) ?? [];
    list.push(toPhotoDto(photo));
    perStop.set(photo.stop_slug, list);
  }

  const stopDtos: StopDto[] = stops.map((row) => ({
    slug: row.slug,
    name: row.name,
    lat: row.lat,
    lon: row.lon,
    photos: perStop.get(row.slug) ?? [],
  }));

  return { trip: { slug: trip.slug, name: trip.name, stops: stopDtos }, focusStop: stopSlug };
}

/** L'hash del token di scrittura del viaggio a cui appartiene questa tappa. */
export async function getWriteTokenHashByStop(db: D1Database, stopSlug: string): Promise<string | null> {
  const row = await db
    .prepare(
      `SELECT t.write_token_hash AS hash
         FROM trips t
         JOIN stops s ON s.trip_slug = t.slug
        WHERE s.slug = ?`,
    )
    .bind(stopSlug)
    .first<{ hash: string }>();

  return row?.hash ?? null;
}

/** Viaggi e tappe per il menu. Nessun token, nessun hash: questa roba finisce nel DOM. */
export async function listTrips(db: D1Database): Promise<TripSummaryDto[]> {
  const { results: trips } = await db
    .prepare('SELECT slug, name, created_at FROM trips ORDER BY created_at DESC')
    .all<{ slug: string; name: string; created_at: number }>();

  const { results: stops } = await db
    .prepare(
      `SELECT s.slug, s.trip_slug, s.name,
              (SELECT COUNT(*) FROM photos p WHERE p.stop_slug = s.slug) AS photo_count
         FROM stops s
        ORDER BY s.created_at ASC`,
    )
    .all<{ slug: string; trip_slug: string; name: string; photo_count: number }>();

  return trips.map((trip) => ({
    slug: trip.slug,
    name: trip.name,
    createdAt: trip.created_at,
    stops: stops
      .filter((s) => s.trip_slug === trip.slug)
      .map((s) => ({ slug: s.slug, name: s.name, photoCount: s.photo_count })),
  }));
}

/**
 * Registra una foto e restituisce la posizione che le è stata assegnata.
 *
 * L'ordinamento è per data di scatto crescente. Le foto senza EXIF finiscono in coda
 * nell'ordine in cui sono arrivate: `sort_index` viene calcolato dalla data quando c'è,
 * e dal massimo corrente + 1 quando manca.
 */
export async function insertPhoto(
  db: D1Database,
  photo: {
    id: string;
    stopSlug: string;
    key: string;
    thumbKey: string;
    width: number;
    height: number;
    takenAt: number | null;
  },
): Promise<number> {
  const sortIndex = photo.takenAt ?? (await nextTailIndex(db, photo.stopSlug));

  await db
    .prepare(
      `INSERT INTO photos
         (id, stop_slug, r2_key, thumb_key, width, height, taken_at, sort_index, created_at)
       VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)`,
    )
    .bind(
      photo.id,
      photo.stopSlug,
      photo.key,
      photo.thumbKey,
      photo.width,
      photo.height,
      photo.takenAt,
      sortIndex,
      Date.now(),
    )
    .run();

  return sortIndex;
}

/**
 * Una posizione oltre l'ultima occupata. Parte da Date.now() perché gli indici delle
 * foto con EXIF sono timestamp: una foto senza data deve finire dopo di loro, non in
 * mezzo.
 */
async function nextTailIndex(db: D1Database, stopSlug: string): Promise<number> {
  const row = await db
    .prepare('SELECT MAX(sort_index) AS max_index FROM photos WHERE stop_slug = ?')
    .bind(stopSlug)
    .first<{ max_index: number | null }>();

  const highest = row?.max_index ?? 0;
  return Math.max(highest + 1, Date.now());
}

export async function getPhotoRow(db: D1Database, stopSlug: string, photoId: string): Promise<PhotoRow | null> {
  return db
    .prepare('SELECT * FROM photos WHERE id = ? AND stop_slug = ?')
    .bind(photoId, stopSlug)
    .first<PhotoRow>();
}

export async function deletePhoto(db: D1Database, stopSlug: string, photoId: string): Promise<void> {
  await db.prepare('DELETE FROM photos WHERE id = ? AND stop_slug = ?').bind(photoId, stopSlug).run();
}

/**
 * Cancella un viaggio con tutto quello che ci sta dentro e restituisce le chiavi R2
 * rimaste orfane.
 *
 * Le righe se ne vanno da sole per vincolo di chiave esterna, i blob no: R2 non sa niente
 * di SQL. Chi chiama deve cancellarli, e per farlo deve saperne i nomi — da qui il valore
 * di ritorno.
 */
export async function deleteTrip(db: D1Database, tripSlug: string): Promise<string[]> {
  const { results } = await db
    .prepare(
      `SELECT p.r2_key, p.thumb_key
         FROM photos p
         JOIN stops s ON s.slug = p.stop_slug
        WHERE s.trip_slug = ?`,
    )
    .bind(tripSlug)
    .all<{ r2_key: string; thumb_key: string }>();

  await db
    .prepare('DELETE FROM photos WHERE stop_slug IN (SELECT slug FROM stops WHERE trip_slug = ?)')
    .bind(tripSlug)
    .run();
  await db.prepare('DELETE FROM stops WHERE trip_slug = ?').bind(tripSlug).run();
  await db.prepare('DELETE FROM trips WHERE slug = ?').bind(tripSlug).run();

  return results.flatMap((row) => [row.r2_key, row.thumb_key]);
}

/** Dump completo dell'indice, per il backup settimanale. Non contiene chiavi né token. */
export async function dumpAll(
  db: D1Database,
): Promise<{ trips: unknown[]; stops: unknown[]; photos: unknown[] }> {
  const trips = await db.prepare('SELECT slug, name, created_at FROM trips').all();
  const stops = await db.prepare('SELECT slug, trip_slug, name, lat, lon, created_at FROM stops').all();
  const photos = await db.prepare('SELECT * FROM photos').all();
  return { trips: trips.results, stops: stops.results, photos: photos.results };
}
```

```ts
  MASTER_TOKEN_HASH: string;

/**
 * Serve un blob cifrato.
 *
 * Volutamente senza autenticazione: il contenuto è ciphertext, e senza la chiave — che
 * sta nel frammento dell'URL e non arriva mai qui — non è distinguibile da rumore. In
 * cambio la risposta è cacheabile dalla CDN, quindi il Worker viene toccato una volta
 * sola per file invece che a ogni visita.
 */
app.get('/media/*', async (c) => {
  const key = c.req.path.slice('/media/'.length);
  if (!key) return c.notFound();

  const cache = caches.default;
  const cached = await cache.match(c.req.raw);
  if (cached) return cached;

  const object = await c.env.MEDIA.get(key);
  if (!object) return c.notFound();

  const response = new Response(object.body, {
    headers: {
      'Content-Type': 'application/octet-stream',
      // I blob sono immutabili per costruzione: la chiave R2 contiene un id casuale,
      // quindi un contenuto diverso ha sempre un URL diverso.
      'Cache-Control': 'public, max-age=31536000, immutable',
      ETag: object.httpEtag,
    },
```

```ts
/**
 * La rotta fra due tappe, disegnata come la percorrerebbe un aereo.
 *
 * Perché non basta una linea dritta: MapLibre disegna un `LineString` come segmento
 * dritto nello spazio proiettato. Su Mercator quel segmento non è il cammino più breve, e
 * a zoom largo la differenza è vistosa — Tokyo–San Francisco taglierebbe l'oceano in
 * orizzontale invece di curvare verso nord. Sembrerebbe un errore di disegno, non una
 * rotta. Quindi l'arco lo interpoliamo noi, punto per punto, sulla sfera.
 *
 * Nessuna dipendenza da MapLibre qui dentro: è aritmetica pura, e si prova senza browser.
 */

export interface LngLat {
  lon: number;
  lat: number;
}

const RAD = Math.PI / 180;
const DEG = 180 / Math.PI;

/** Quanti punti per tratta. 64 è già indistinguibile da una curva vera su uno schermo. */
export const DEFAULT_STEPS = 64;

/**
 * Interpolazione sferica fra due punti: restituisce `steps + 1` coppie `[lon, lat]`,
 * estremi compresi.
 */
export function greatCircle(a: LngLat, b: LngLat, steps = DEFAULT_STEPS): Array<[number, number]> {
  const lat1 = a.lat * RAD;
  const lon1 = a.lon * RAD;
  const lat2 = b.lat * RAD;
  const lon2 = b.lon * RAD;

  const d =
    2 *
    Math.asin(
      Math.min(
        1,
        Math.sqrt(
          Math.sin((lat2 - lat1) / 2) ** 2 +
            Math.cos(lat1) * Math.cos(lat2) * Math.sin((lon2 - lon1) / 2) ** 2,
        ),
      ),
    );

  // Due tappe nello stesso punto: nessun arco da interpolare, e dividere per sin(0)
  // produrrebbe solo NaN.
  if (!Number.isFinite(d) || d === 0) {
    return unwrap([
      [a.lon, a.lat],
      [b.lon, b.lat],
    ]);
  }

  const points: Array<[number, number]> = [];
  for (let i = 0; i <= steps; i++) {
    const f = i / steps;
    const A = Math.sin((1 - f) * d) / Math.sin(d);
    const B = Math.sin(f * d) / Math.sin(d);

    const x = A * Math.cos(lat1) * Math.cos(lon1) + B * Math.cos(lat2) * Math.cos(lon2);
    const y = A * Math.cos(lat1) * Math.sin(lon1) + B * Math.cos(lat2) * Math.sin(lon2);
    const z = A * Math.sin(lat1) + B * Math.sin(lat2);

    points.push([Math.atan2(y, x) * DEG, Math.atan2(z, Math.hypot(x, y)) * DEG]);
  }

  return unwrap(points);
}

/** Tutte le tratte del viaggio in un'unica linea, pronta da dare a MapLibre. */
export function routeGeoJson(stops: LngLat[], steps = DEFAULT_STEPS) {
  const coordinates: Array<[number, number]> = [];

  for (let i = 1; i < stops.length; i++) {
    const arc = greatCircle(stops[i - 1]!, stops[i]!, steps);
    // Il primo punto di ogni tratta è l'ultimo della precedente: metterlo due volte
    // lascerebbe un punto doppio dove il tratteggio si vede addensare.
    coordinates.push(...(i === 1 ? arc : arc.slice(1)));
  }

  return {
    type: 'Feature' as const,
    properties: {} as Record<string, never>,
    geometry: { type: 'LineString' as const, coordinates: unwrap(coordinates) },
  };
}

/**
 * Srotola le longitudini così che due punti consecutivi non saltino mai di 360 gradi.
 *
 * Senza, una rotta che attraversa l'antimeridiano passa da +179 a -179 e MapLibre la
 * disegna come una riga che torna indietro attraversando tutto il mondo. Uscire dal
 * campo -180…180 è lecito e voluto: la mappa lo gestisce.
 */
function unwrap(points: Array<[number, number]>): Array<[number, number]> {
  if (points.length === 0) return [];

  const out: Array<[number, number]> = [points[0]!];
  let offset = 0;

  for (let i = 1; i < points.length; i++) {
    const delta = points[i]![0] - points[i - 1]![0];
    if (delta > 180) offset -= 360;
    else if (delta < -180) offset += 360;
    out.push([points[i]![0] + offset, points[i]![1]]);
  }

  return out;
}
```

```ts
/**
 * Le due decisioni che trasformano uno scorrimento in un volo, tenute fuori dal DOM
 * perché sono l'unica parte davvero sbagliabile e l'unica che vale la pena provare.
 *
 * `activeStop` dice quale tappa si sta guardando. `FlightDirector` decide cosa farne.
 */

export interface StopBox {
  slug: string;
  /** Coordinate nel documento, non nello schermo: crescono verso il basso. */
  top: number;
  bottom: number;
}

/**
 * La tappa attraversata dalla linea di riferimento.
 *
 * Sopra la prima e sotto l'ultima non restituisce null ma l'estremo più vicino: durante il
 * rimbalzo elastico di iOS la linea esce dal documento, e in quel momento la mappa non
 * deve smettere di sapere dov'è.
 *
 * Presuppone i riquadri già ordinati, come li produce l'ordine del documento.
 */
export function activeStop(boxes: StopBox[], line: number): string | null {
  if (boxes.length === 0) return null;

  for (const box of boxes) {
    if (line >= box.top && line < box.bottom) return box.slug;
  }

  return line < boxes[0]!.top ? boxes[0]!.slug : boxes.at(-1)!.slug;
}

/**
 * Chiede voli alla mappa senza mai accodarli.
 *
 * Il motivo è tutto in una scorsa veloce: attraversare cinque tappe in un secondo
 * genererebbe cinque richieste, e una coda le eseguirebbe una dopo l'altra continuando a
 * volare per svariati secondi dopo che le dita si sono fermate. Qui l'ultima richiesta
 * vince e le intermedie vengono buttate: quando il volo in corso finisce, si parte
 * direttamente per dove si sta guardando adesso.
 */
export class FlightDirector {
  private running = false;
  private target: string | null = null;
  private queued: string | null = null;

  constructor(private readonly fly: (slug: string) => Promise<void>) {}

  request(slug: string): void {
    if (slug === this.target) {
      // Già lì, o già in viaggio verso lì.
      this.queued = null;
      return;
    }

    if (this.running) {
      this.queued = slug;
      return;
    }

    void this.run(slug);
  }

  private async run(slug: string): Promise<void> {
    this.running = true;
    this.target = slug;

    try {
      await this.fly(slug);
    } catch {
      // Un volo fallito è un fotogramma perso, non un guasto: si riparte al prossimo
      // scorrimento. Ingoiarlo qui è quello che impedisce al regista di restare bloccato.
      this.target = null;
    } finally {
      this.running = false;
    }

    const next = this.queued;
    this.queued = null;
    if (next && next !== this.target) void this.run(next);
  }
}
```

```ts
 *

 * E siccome la chiave è del viaggio, condividere condivide il viaggio intero: l'interfaccia
 * deve dirlo, non far credere il contrario.

  keyMaterial: string | null;

export function parseRoute(href: string): Route {
  const url = new URL(href);
  const segments = url.pathname.split('/').filter(Boolean);

  if (segments[0] === 'p' && segments[1]) {
    return {
      kind: 'stop',
      slug: segments[1],
      keyMaterial: url.hash ? url.hash.slice(1) : null,
      writeTokenFromUrl: url.searchParams.get('w'),
    };
  }

  if (segments[0] === 'm' && segments[1]) {
    return { kind: 'master', masterToken: segments[1] };
  }

  return { kind: 'unknown' };
}
```

```ts
 * Le chiamate al Worker. Nessun altro file fa fetch verso l'API.
 *
 * Attenzione a una cosa sola: qui passano blob già cifrati e riferimenti, mai chiavi.
 * Se un giorno una funzione di questo file accettasse una CryptoKey, sarebbe il segnale

import type {
  CreateStopRequest,
  CreateStopResponse,
  CreateTripRequest,
  CreateTripResponse,
  RegisterPhotoRequest,
  RegisterPhotoResponse,
  TripSummaryDto,
  TripViewDto,
  UploadMediaResponse,
} from '../../shared/api-types';

export class ApiError extends Error {
  constructor(
    message: string,
    readonly status: number,
  ) {
    super(message);
  }
}

async function parse<T>(response: Response): Promise<T> {
  if (!response.ok) {
    const body = (await response.json().catch(() => null)) as { error?: string } | null;
    throw new ApiError(body?.error ?? `errore ${response.status}`, response.status);
  }
  return response.json() as Promise<T>;
}

const asJson = (token: string) => ({
  Authorization: `Bearer ${token}`,
  'Content-Type': 'application/json',
});

// --- Lettura -----------------------------------------------------------------

/**
 * Il viaggio intero a partire dalla tappa toccata. Non richiede token: senza chiave i
 * riferimenti sono inerti.
 */
export async function fetchTripByStop(stopSlug: string): Promise<TripViewDto> {
  return parse(await fetch(`/api/stops/${stopSlug}`));
}

export function mediaUrl(key: string): string {
  return `/media/${key}`;
}

export async function fetchEncrypted(key: string): Promise<ArrayBuffer> {
  const response = await fetch(mediaUrl(key));
  if (!response.ok) throw new ApiError(`media non trovato: ${key}`, response.status);
  return response.arrayBuffer();
}

// --- Scrittura, col token del viaggio ----------------------------------------

export async function uploadMedia(
  stopSlug: string,
  writeToken: string,
  blob: Blob,
  kind: 'full' | 'thumb',
): Promise<string> {
  const response = await fetch(`/api/stops/${stopSlug}/media`, {
    method: 'POST',
    headers: { Authorization: `Bearer ${writeToken}`, 'X-Media-Kind': kind },
    body: blob,
  });
  const body = await parse<UploadMediaResponse>(response);
  return body.key;
}

export async function registerPhoto(
  stopSlug: string,
  writeToken: string,
  photo: RegisterPhotoRequest,
): Promise<RegisterPhotoResponse> {

    await fetch(`/api/stops/${stopSlug}/photos`, {

}

      headers: { Authorization: `Bearer ${writeToken}` },

  );
}

export async function createTrip(masterToken: string, trip: CreateTripRequest): Promise<CreateTripResponse> {
```

```ts
  }

  /**
   * Risolve quando lo stile è caricato, la rotta è disegnata e si può iniziare a volare.
   *
   * Non aspetta all'infinito: se le mappe non arrivano — rete lenta, CARTO giù, WebGL
   * assente — dopo qualche secondo si prosegue comunque. Meglio le foto senza volo che
   * una pagina bianca.
   */
  async ready(): Promise<void> {
    if (!this.map.loaded()) {
      await Promise.race([
        new Promise<void>((resolve) => this.map.once('load', () => resolve())),
        new Promise<void>((resolve) => setTimeout(resolve, STYLE_TIMEOUT_MS)),
      ]);
    }

    try {
      // Il globo invece della mappa piatta: alla partenza si deve vedere che è la Terra.
      // Va impostato a stile caricato, non nelle opzioni del costruttore.
      this.map.setProjection({ type: 'globe' });
    } catch {
      // Proiezione non supportata: resta la mappa piatta, che va benissimo.
    }

    this.drawRoute();
  }

  /**
   * La rotta tratteggiata, disegnata prima del volo: alla partenza il globo la mostra
   * intera, ed è lì che si capisce che quello è un viaggio e non un posto.
   */
  private drawRoute(): void {
    if (this.options.stops.length < 2) return;

    try {
      this.map.addSource(ROUTE_SOURCE, {
        type: 'geojson',
        data: routeGeoJson(this.options.stops.map((s) => ({ lon: s.lon, lat: s.lat }))),
      });

      this.map.addLayer({
        id: ROUTE_LAYER,
        type: 'line',
        source: ROUTE_SOURCE,
        layout: { 'line-cap': 'round', 'line-join': 'round' },
        paint: {
          'line-color': '#7fd8ec',
          'line-opacity': 0.45,
          'line-width': 1.4,
          'line-dasharray': [2, 3],
        },
      });
    } catch {
      // Stile mai arrivato: niente rotta. Le tappe e le foto restano al loro posto.
    }
  }

  /** Il volo d'arrivo: scende sulla tappa toccata e ci pianta i pin. Risolve a volo finito. */
  async flyToFocus(): Promise<void> {
    const stop = this.stop(this.options.focus) ?? this.options.stops[0];
    if (!stop) return;

    this.map.flyTo({
      center: [stop.lon, stop.lat],
      zoom: ARRIVAL_ZOOM,
      // Il globo ruota e la camera si inclina mentre scende: sono questi due, più del
      // solo zoom, a far sembrare la scena un avvicinamento invece di un ingrandimento.
      bearing: 0,
      pitch: ARRIVAL_PITCH,
      duration: FLIGHT_MS,
      // Parte deciso e si posa piano, come una discesa vera.
      curve: 1.6,
      // Tiene in piedi l'effetto per chi ha attivato la riduzione del movimento a livello
      // di sistema: senza, MapLibre salterebbe al punto d'arrivo e il sipario cadrebbe
      // prima che le miniature siano pronte.
      essential: true,
    });

    /*
     * Si aspetta il tempo, non l'evento `moveend`.
     *
     * Sembrerebbe più pulito aspettare l'evento, e invece era un bug: il cambio di
     * proiezione a globo genera un `moveend` per conto suo, che arrivava subito dopo la
     * partenza e veniva scambiato per "volo concluso". Risultato, le foto comparivano
     * dopo mezzo secondo e dell'animazione non si vedeva niente.
     *
     * La durata la decidiamo noi e la passiamo a flyTo: aspettarla è sia più semplice
     * sia più fedele all'idea di partenza, cioè che questo intervallo è il budget
     * entro cui la decifratura deve avere finito.
     */
    await new Promise<void>((resolve) => setTimeout(resolve, FLIGHT_MS));

    this.dropPins();
    this.setActive(this.options.focus);
  }

  /** Il volo comandato dallo scorrimento. Risolve quando è finito, non prima. */
  async flyToStop(slug: string): Promise<void> {
    const stop = this.stop(slug);
    if (!stop) return;

    this.setActive(slug);

    this.map.flyTo({
      center: [stop.lon, stop.lat],
      zoom: ARRIVAL_ZOOM,
      bearing: 0,
      pitch: ARRIVAL_PITCH,
      duration: SCROLL_FLIGHT_MS,
      curve: 1.4,
      essential: true,
    });

    await new Promise<void>((resolve) => setTimeout(resolve, SCROLL_FLIGHT_MS));
  }

  /**
   * Da chiamare quando il contenitore cambia altezza — cioè quando la mappa si ritira
   * dallo schermo pieno alla fascia. MapLibre non se ne accorge da solo, e senza questa
   * chiamata la tela resta alta 100vh dentro un contenitore alto 42vh.
   */
  resize(): void {
    this.map.resize();
  }

  private dropPins(): void {
    for (const stop of this.options.stops) {
      const element = document.createElement('div');
      element.className = 'pin';
      element.dataset.slug = stop.slug;

      new maplibregl.Marker({ element }).setLngLat([stop.lon, stop.lat]).addTo(this.map);
      this.markers.set(stop.slug, element);
    }
  }

  private setActive(slug: string): void {
    if (this.active === slug) return;

    if (this.active) this.markers.get(this.active)?.classList.remove('pin--active');
    this.markers.get(slug)?.classList.add('pin--active');
    this.active = slug;
  }

  private stop(slug: string): MapStop | undefined {
    return this.options.stops.find((s) => s.slug === slug);
  }

  destroy(): void {
    this.markers.clear();
    this.map.remove();
  }
}
```

```ts
/**
 * Una tappa nel documento: la barra col nome, la griglia delle sue foto, e il "+".
 *
 * Esiste come pezzo a sé perché ogni tappa ha uno stato che le appartiene — il suo elenco
 * di foto, che cambia caricando e cancellando — e tenerlo tutto nella pagina significava
 * un solo file che sapeva tutto di tutte.
 */

import type { PhotoDto, StopDto } from '../../shared/api-types';
import type { PhotoStore } from '../lib/photo-store';
import { Gallery } from './gallery';
import { UploadPanel } from './upload-panel';

export interface StopSectionOptions {
  stop: StopDto;
  store: PhotoStore;
  /** Null per chi è arrivato da un link condiviso: niente "+", niente "Elimina". */
  writeToken: string | null;
  /** La chiave del viaggio, per cifrare quello che si carica. */
  key: CryptoKey;
  /** Apre il visore su questa tappa, alla foto scelta. */
  onOpen: (photos: PhotoDto[], index: number) => void;
  /** Cancella davvero, e restituisce solo quando il server ha detto di sì. */
  onDelete: (stopSlug: string, photo: PhotoDto) => Promise<void>;
}

export class StopSection {
  readonly element: HTMLElement;
  private photos: PhotoDto[];
  private gallery: Gallery | null = null;
  private readonly galleryHost: HTMLElement;
  private readonly meta: HTMLElement;

  constructor(private readonly options: StopSectionOptions) {
    this.photos = [...options.stop.photos];

    this.element = document.createElement('section');
    this.element.className = 'stop';
    this.element.dataset.slug = options.stop.slug;

    const bar = document.createElement('header');
    bar.className = 'stop-bar';

    const name = document.createElement('span');
    name.className = 'stop-bar__name';
    name.textContent = options.stop.name;

    this.meta = document.createElement('span');
    this.meta.className = 'stop-bar__meta';
    this.meta.textContent = describeSpan(this.photos);

    bar.append(name, this.meta);

    this.galleryHost = document.createElement('div');
    this.galleryHost.className = 'gallery';

    this.element.append(bar, this.galleryHost);
    this.redraw();

    if (options.writeToken) {
      new UploadPanel({
        container: this.element,
        slug: options.stop.slug,
        writeToken: options.writeToken,
        key: options.key,
        onFinished: (added) => {
          this.photos = [...this.photos, ...added].sort((a, b) => a.sortIndex - b.sortIndex);
          this.redraw();
          this.refreshMeta();
        },
      });
    }
  }

  /** L'elenco corrente, per il visore: cambia caricando e cancellando. */
  currentPhotos(): PhotoDto[] {
    return this.photos;
  }

  async removePhoto(photo: PhotoDto): Promise<void> {
    await this.options.onDelete(this.options.stop.slug, photo);
    this.photos = this.photos.filter((p) => p.id !== photo.id);
    this.redraw();
    this.refreshMeta();
  }

  private redraw(): void {
    this.gallery?.destroy();
    this.galleryHost.replaceChildren();

    if (this.photos.length === 0) {
      this.galleryHost.append(emptyState(Boolean(this.options.writeToken)));
      return;
    }

    this.gallery = new Gallery({
      container: this.galleryHost,
      photos: this.photos,
      store: this.options.store,
      onOpen: (index) => this.options.onOpen(this.photos, index),
    });
  }

  /**
   * Riallinea la barra all'elenco corrente.
   *
   * Serve perché caricare o cancellare foto cambia due cose insieme — la griglia e il
   * conteggio — e aggiornarne solo una lascia sullo schermo la contraddizione più
   * fastidiosa possibile: "0 foto" scritto sopra tre foto.
   */
  private refreshMeta(): void {
    this.meta.textContent = describeSpan(this.photos);
  }

  destroy(): void {
    this.gallery?.destroy();
  }
}

/** "13 – 15 aprile 2026 · 22 foto", o solo il conteggio se l'EXIF non c'era. */
export function describeSpan(photos: PhotoDto[]): string {
  const dates = photos.map((p) => p.takenAt).filter((d): d is number => typeof d === 'number');
  const count = `${photos.length} foto`;
  if (dates.length === 0) return count;

  const format = (ms: number) =>
    new Date(ms).toLocaleDateString('it-IT', { day: 'numeric', month: 'long', year: 'numeric' });

  const first = format(Math.min(...dates));
  const last = format(Math.max(...dates));

  return first === last ? `${first} · ${count}` : `${first} – ${last} · ${count}`;
}

function emptyState(canUpload: boolean): HTMLElement {
  const empty = document.createElement('p');
  empty.className = 'empty';
  empty.textContent = canUpload
    ? 'Ancora nessuna foto qui. Tocca "+ Aggiungi foto" per cominciare.'
    : 'Qui non c\'è ancora niente.';
  return empty;
}
```

```ts
/**
 * La pagina che si apre toccando il magnete: un viaggio intero, percorribile scorrendo.
 *
 * La sequenza d'arrivo è pensata perché il tempo di decifratura non si veda mai:
 *
 *   1. si chiede il viaggio (metadati leggeri, nessuna immagine)
 *   2. parte il volo sul globo verso la tappa toccata
 *   3. mentre la camera scende, le miniature di quella tappa vengono decifrate
 *   4. il volo finisce, i pin si aprono, il titolo compare sulla mappa
 *
 * Il punto 3 è il motivo per cui il punto 2 esiste. Non invertirli.
 *
 * All'arrivo NON si mostra nessuna foto: la mappa resta padrona dello schermo e le foto
 * cominciano al primo gesto. Da quel momento la pagina cambia regime — la mappa si ritira
 * in una fascia in alto e ci resta, e lo scorrimento comanda i voli fra le tappe.
 *
 * Le tappe che non si raggiungono non costano niente: le loro miniature le chiede la
 * griglia, un riquadro alla volta, quando stanno per entrare nello schermo.
 */

import type { PhotoDto, TripViewDto } from '../../shared/api-types';
import { deletePhoto, fetchTripByStop } from '../lib/api-client';
import { importKey } from '../lib/crypto';
import { PhotoStore } from '../lib/photo-store';
import { activeStop, FlightDirector } from '../lib/scroll-flight';
import { buildShareUrl, cleanedUrl, resolveWriteToken, type StopRoute } from '../lib/session';
import { MapScene } from '../scenes/map-scene';
import { describeSpan, StopSection } from '../scenes/stop-section';
import { Viewer } from '../scenes/viewer';

/** Quante miniature della tappa d'arrivo preparare durante il volo. */
const PRELOAD_COUNT = 12;

/**
 * Quanto è alta la fascia della mappa, in frazione di schermo. Deve combaciare con
 * `--fascia` in styles.css: la usa il CSS per lo spazio, e questo file per capire dove
 * portare lo scorrimento.
 */
const BAND_RATIO = 0.42;

/**
 * Dove passa la linea che decide la tappa attiva: al 62% dello schermo, cioè ben sotto la
 * fascia e in mezzo all'area in cui si guardano le foto. Più in alto la tappa cambierebbe
 * mentre le sue foto sono ancora quasi tutte in vista.
 */
const REFERENCE_LINE = 0.62;

export async function renderTripPage(root: HTMLElement, route: StopRoute): Promise<void> {
  if (!route.keyMaterial) {
    return renderMessage(root, 'Link incompleto', 'Manca la parte dopo il #, quella che apre le foto. Riprova a toccare il magnete.');
  }

  let key: CryptoKey;
  try {
    key = await importKey(route.keyMaterial);
  } catch {
    return renderMessage(root, 'Link non valido', 'La chiave in questo link non è utilizzabile.');
  }

  let view: TripViewDto;
  try {
    view = await fetchTripByStop(route.slug);
  } catch {
    return renderMessage(root, 'Posto non trovato', 'Questo link non porta da nessuna parte.');
  }

  // Il token arriva dal tag la prima volta, poi vive in localStorage su questo telefono.
  const writeToken = resolveWriteToken(localStorage, route);
  if (route.writeTokenFromUrl) {
    // Via dalla barra degli indirizzi: se l'utente copia l'URL a mano non deve regalare
    // il potere di scrittura. La chiave invece resta, o un ricaricamento non aprirebbe più nulla.
    history.replaceState(null, '', cleanedUrl(location.href));
  }

  const store = new PhotoStore(key);
  root.replaceChildren();

  const mapLayer = document.createElement('div');
  mapLayer.className = 'map';

  const content = document.createElement('main');
  content.className = 'content';

  root.append(mapLayer, content);

  /*
   * Il visore è uno solo, e "Elimina" deve togliere la foto dalla tappa giusta: qui si
   * tiene da parte quale sezione l'ha aperto. Senza, la cancellazione andrebbe sempre a
   * finire sull'ultima tappa costruita.
   */
  let openSection: StopSection | null = null;

  const viewer = new Viewer(
    [],
    store,
    writeToken
      ? {
          onDelete: async (photo: PhotoDto) => {
            await openSection?.removePhoto(photo);
          },
        }
      : {},
  );

  const sections: StopSection[] = view.trip.stops.map((stop) => {
    const section: StopSection = new StopSection({
      stop,
      store,
      writeToken,
      key,
      onOpen: (photos, index) => {
        openSection = section;
        viewer.setPhotos(photos);
        void viewer.open(index);
      },
      onDelete: async (stopSlug, photo) => {
        if (!writeToken) return;
        await deletePhoto(stopSlug, writeToken, photo.id);
      },
    });
    return section;
  });

  const list = document.createElement('div');
  list.className = 'stops';
  list.append(...sections.map((s) => s.element));
  content.append(list);

  // Il sipario: sovrapposto e fuori dal flusso, così quando sparisce non sposta niente e
  // non c'è nessuna posizione di scorrimento da inseguire.
  const focus = view.trip.stops.find((s) => s.slug === view.focusStop) ?? view.trip.stops[0];
  const curtain = buildCurtain(view, focus?.slug ?? view.focusStop, route.keyMaterial);
  root.append(curtain);

  // Lo scorrimento è bloccato finché il sipario è alzato: è una scena, e non deve poter
  // essere scavalcata a metà.
  document.body.classList.add('is-locked');

  // Se il browser non regge la mappa si prosegue senza: le foto non dipendono da lei.
  const scene = MapScene.create({
    container: mapLayer,
    stops: view.trip.stops.map((s) => ({ slug: s.slug, name: s.name, lat: s.lat, lon: s.lon })),
    focus: view.focusStop,
  });
  await scene?.ready();

  // Volo e decifratura partono insieme: è l'intero trucco della pagina. Solo miniature,
  // e solo della tappa d'arrivo — all'arrivo non si vede nessuna foto grande, quindi
  // scaricarne una sarebbe lavoro speso per niente proprio quando il tempo conta.
  const preloadKeys = (focus?.photos ?? []).slice(0, PRELOAD_COUNT).map((p) => p.thumbKey);
  await Promise.all([scene?.flyToFocus(), store.preload(preloadKeys)]);

  curtain.classList.add('curtain--shown');

  armFirstGesture(() => {
    reveal({ curtain, mapLayer, content, sections, scene, focusSlug: view.focusStop });
  });

  window.addEventListener('pagehide', () => {
    store.revokeAll();
    for (const section of sections) section.destroy();
    scene?.destroy();
  }, { once: true });
}

interface RevealOptions {
  curtain: HTMLElement;
  mapLayer: HTMLElement;
  content: HTMLElement;
  sections: StopSection[];
  scene: MapScene | null;
  focusSlug: string;
}

/**
 * Il primo gesto fa tre cose insieme: il sipario svanisce, la mappa si ritira nella
 * fascia, il documento compare già posizionato sulla tappa toccata.
 */
function reveal(options: RevealOptions): void {
  const { curtain, mapLayer, content, sections, scene, focusSlug } = options;

  document.body.classList.remove('is-locked');
  content.classList.add('content--revealed');
  curtain.classList.add('curtain--gone');
  // Rimosso davvero, non solo trasparente: un sovrapposto a schermo intero invisibile che
  // resta nel documento è il modo più sicuro per ritrovarsi tocchi che non arrivano.
  setTimeout(() => curtain.remove(), 600);

  if (scene) {
    mapLayer.classList.add('map--band');
    // MapLibre non si accorge da solo che il contenitore ha cambiato altezza: senza
    // questa chiamata la tela resta alta uno schermo dentro una fascia.
    mapLayer.addEventListener('transitionend', () => scene.resize(), { once: true });
  }

  const band = scene ? window.innerHeight * BAND_RATIO : 0;
  const target = sections.find((s) => s.element.dataset.slug === focusSlug);
  if (target) {
    const top = target.element.getBoundingClientRect().top + window.scrollY - band;
    window.scrollTo({ top: Math.max(0, top), behavior: 'instant' });
  }

  if (scene) watchScroll(sections, scene);
}

/** Il primo movimento, qualunque forma abbia. Vale una volta sola. */
function armFirstGesture(onGesture: () => void): void {
  let fired = false;
  const fire = () => {
    if (fired) return;
    fired = true;
    for (const name of ['wheel', 'touchstart', 'keydown', 'click'] as const) {
      window.removeEventListener(name, fire);
    }
    onGesture();
  };

  for (const name of ['wheel', 'touchstart', 'keydown', 'click'] as const) {
    window.addEventListener(name, fire, { passive: true });
  }
}

/**
 * Lega lo scorrimento ai voli.
 *
 * Le misure si rileggono a ogni fotogramma utile invece di essere memorizzate: le sezioni
 * cambiano altezza quando si caricano o si cancellano foto, e una misura vecchia farebbe
 * volare la mappa sulla tappa sbagliata.
 */
function watchScroll(sections: StopSection[], scene: MapScene): void {
  const director = new FlightDirector((slug) => scene.flyToStop(slug));
  let scheduled = false;

  const onScroll = () => {
    if (scheduled) return;
    scheduled = true;

    requestAnimationFrame(() => {
      scheduled = false;

      const boxes = sections.map((section) => {
        const rect = section.element.getBoundingClientRect();
        return {
          slug: section.element.dataset.slug ?? '',
          top: rect.top + window.scrollY,
          bottom: rect.bottom + window.scrollY,
        };
      });

      const slug = activeStop(boxes, window.scrollY + window.innerHeight * REFERENCE_LINE);
      if (slug) director.request(slug);
    });
  };

  window.addEventListener('scroll', onScroll, { passive: true });
}

/**
 * La scena d'arrivo: il nome della tappa, con quello del viaggio sopra.

 * L'occhiello non è ornamento: senza, "Chiang Mai" da solo non dice che dietro c'è un

  const scrim = document.createElement('div');
  scrim.className = 'curtain__scrim';

  header.className = 'curtain__header';

  overline.className = 'curtain__trip';

  share.type = 'button';
  share.className = 'share';

 * Condivide il viaggio e non la singola tappa, perché la chiave è del viaggio: fingere il

async function shareLink(
  tripName: string,
  stopSlug: string,
  keyMaterial: string,
  button: HTMLButtonElement,

  button.textContent = 'Link copiato';
  setTimeout(() => (button.textContent = original), 2000);
}
```

```ts
 * Il pannello da cui nascono i viaggi e le tappe.
 *
 * Fa tre cose, e la terza è la più importante:
 *   1. crea il viaggio, e le tappe dentro di esso
 *   2. genera la chiave di cifratura QUI, nel browser, e la mette solo negli URL dei tag
 *   3. ricorda chiavi e token, e insiste perché vengano esportati

 * La chiave non viene mai inviata al server. Il server non sa nemmeno che esiste — e per
 * questo un viaggio creato su un altro browser si può elencare ma non ampliare: senza la
 * sua chiave, l'URL di una tappa nuova non si potrebbe nemmeno scrivere.
 */

import type { TripSummaryDto } from '../../shared/api-types';
import { createStop, createTrip, deleteTrip, fetchTrips } from '../lib/api-client';

const LAST_EXPORT_KEY = 'ricordi:keychain:exported-at';

export function buildMenuPanel(masterToken: string): HTMLElement {
  const panel = document.createElement('div');
  panel.className = 'panel';

  const title = document.createElement('h1');
  title.textContent = 'Viaggi';

  const warning = document.createElement('p');
  warning.className = 'panel__warning';

  const list = document.createElement('ul');
  list.className = 'panel__trips';

  const exportButton = document.createElement('button');
  exportButton.type = 'button';
  exportButton.className = 'panel__export';
  exportButton.textContent = 'Esporta le chiavi';
  exportButton.addEventListener('click', () => {
    downloadKeychain(loadKeychain(localStorage));
    localStorage.setItem(LAST_EXPORT_KEY, String(Date.now()));
    refreshWarning();
  });

  const refreshWarning = () => {
    const entries = loadKeychain(localStorage);
    const lastExport = Number(localStorage.getItem(LAST_EXPORT_KEY)) || null;
    const pending = needsExport(entries, lastExport);

    warning.textContent = pending
      ? 'Ci sono chiavi non ancora esportate. Se questo browser si perde, quelle foto non si riaprono più.'
      : entries.length > 0
        ? 'Tutte le chiavi sono state esportate almeno una volta.'
        : '';
    warning.classList.toggle('panel__warning--urgent', pending);
  };

  /*
   * L'indirizzo da scrivere sul tag vive QUI e non dentro la riga del viaggio, che
   * l'aggiornamento dell'elenco ricostruisce da capo: là dentro comparirebbe e sparirebbe
   * nello stesso istante, proprio l'unica informazione che va copiata a mano.
   */
  const result = document.createElement('code');

    result.hidden = false;
    result.textContent = url;

    const trips = await fetchTrips(masterToken).catch(() => [] as TripSummaryDto[]);

      ...trips.map((trip) => tripRow(trip, keychain, masterToken, refreshAll, showUrl)),
    );
  };

  const refreshAll = async () => {
    refreshWarning();
    await refreshList();

  const form = buildTripForm(async (name) => {
    // La chiave nasce e resta nel browser. Il server riceve solo il nome.
    const key = await generateKey();
    const keyMaterial = await exportKey(key);
    const { slug, writeToken } = await createTrip(masterToken, { name });

    await refreshAll();
  });

  panel.append(title, warning, form, result, exportButton, list);
  void refreshAll();

  return panel;
}

/**
 * Coordinate da nome, con Nominatim di OpenStreetMap: gratuito e senza chiave.
 * Se non risponde non è un dramma — le coordinate si possono sempre scrivere a mano.
 */
async function geocode(query: string): Promise<{ lat: number; lon: number } | null> {
  if (!query.trim()) return null;

  try {
    const url = new URL('https://nominatim.openstreetmap.org/search');
    url.searchParams.set('q', query);
    url.searchParams.set('format', 'json');
    url.searchParams.set('limit', '1');

    const response = await fetch(url, { headers: { Accept: 'application/json' } });
    if (!response.ok) return null;

    const results = (await response.json()) as Array<{ lat: string; lon: string }>;
    const first = results[0];
    return first ? { lat: Number(first.lat), lon: Number(first.lon) } : null;
  } catch {
    return null;
  }
}

function downloadKeychain(entries: KeychainEntry[]): void {
  const url = URL.createObjectURL(exportKeychain(entries));
  const link = document.createElement('a');
  link.href = url;
  link.download = `ricordi-chiavi-${new Date().toISOString().slice(0, 10)}.json`;
  link.click();
  URL.revokeObjectURL(url);
}

function field(label: string, type: string, placeholder: string) {
  const wrapper = document.createElement('label');
  wrapper.className = 'field';

  const text = document.createElement('span');
  text.textContent = label;

  const input = document.createElement('input');
  input.type = type;
  input.placeholder = placeholder;
  if (type === 'number') input.step = 'any';

  wrapper.append(text, input);
  return { wrapper, input };
}
```

   > intercettare tutto. Va nascosto e poi rimosso dal documento. È la terza volta che
   > questo progetto inciampa nella stessa famiglia di problemi — c'è un test di
   > regressione anche per questa.

   > **`map.resize()` dopo la ritirata.** MapLibre non si accorge che il contenitore ha
   > cambiato altezza: senza la chiamata, la tela resta alta uno schermo dentro una fascia
   > alta il 42%.

6. In **Fuori perimetro**, aggiungere: spostare una tappa da un viaggio all'altro
   (cambierebbe la chiave con cui le sue foto sono cifrate: è una ricifratura, non un
   `UPDATE`), e l'evidenziazione della tratta percorsa rispetto alle altre.

## Note di revisione del piano

**Copertura della spec.** Ogni sezione del design ha almeno un task: struttura e chiavi
(1–2), API (3), rotte curve (4), volo sullo scorrimento (5, 9), URL e portachiavi (6),
client (7), mappa e colori (8), pagina e fascia (9), menu (10), test (11), documentazione
(12).

**Due scelte che si scostano dalla spec, con il motivo.**

1. La spec parlava di «miniature delle altre tappe decifrate quando la loro sezione arriva
   a circa uno schermo di distanza», come se servisse un meccanismo nuovo. Non serve:
   `Gallery` ha già un `IntersectionObserver` con `rootMargin: 300px` che carica un
   riquadro alla volta. Il comportamento voluto si ottiene senza scrivere niente, ed è il
   motivo per cui in questo piano non c'è un task dedicato.

2. La spec elencava fra i test «cancellazione in cascata» senza una rotta che la
   provocasse. Qui esiste `DELETE /api/trips/:slug`, col pulsante "Elimina" nel menu: una
   cancellazione a mano dal database non sarebbe stata testabile attraverso l'API, e
   durante lo sviluppo serve comunque un modo per buttare via i viaggi di prova.

**Il valore duplicato da tenere d'occhio.** L'altezza della fascia esiste due volte: come
`--fascia: 42vh` in `styles.css` e come `BAND_RATIO = 0.42` in `pages/trip.ts`. Il CSS ne
ha bisogno per lo spazio, il JavaScript per sapere dove portare lo scorrimento, e non c'è
modo di leggere l'uno dall'altro senza un `getComputedStyle` che costerebbe più di quanto
valga. Sono commentati l'uno con l'altro: se cambia uno va cambiato anche l'altro.
